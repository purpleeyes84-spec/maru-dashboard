# 논리 검증

## 게이트 원칙 (교육검증 이식)
- 근거 없으면 반려. 대충 통과 금지.
- 쉬운 판정 우선. 애매하면 조건부+질문목록.
- 본문·파일을 고치지 않는다. 고치는 건 칸 담당봇.

## 데이터 정합
- 소스(xlsx/json) ↔ 화면 숫자·건수·PO/NO 집합
- 필터(현작업분·납기월·팀)와 실제 포함/제외 집합
- 중복·누락·잘못된 매칭(시즌·브랜드·PO 정규화)
- 빈 납기·(PO없음)·미매칭은 **명시**돼 있어야 함 (숨기면 반려)

## 반복규칙 강화
`rules/*.md`에 등록된 패턴이 있으면:
1. 동일 패턴 재발 → 판결 한 단계 상향(조건부→반려 등) + 재발키
2. 패턴 **이탈 형태**(예: 상대경로 규칙인데 절대경로 혼재) → 논리 확인 강화, 샘플 확대
3. 새 반복 후보 → rules에 초안 1줄 제안(작성은 보고만, 확정은 사용자/Air)
