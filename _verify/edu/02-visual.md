# 시각·UI 검증

캡처·브라우저 file:// 기본 금지. HTML/CSS/경로·에셋 존재로 판정.

## 필수 체크
- 깨진 링크·이미지·PDF·xlsx (상대경로 resolve 후 파일 존재)
- `file:///Z:/...%EC...` 절대경로 / 인코딩 깨짐
- 내비·허브 링크 일관 (칸 이름·상대깊이)
- 레이아웃: 겹침·잘림·빈 큰 구멍·고아 섹션
- 이미지 역할 규칙 위반 (예: 첨부칩만인데 큰 `<img>` 미리보기)
- 한글 깨짐·영문폴백(교육칸)·메타문/프롬프트 잔재 화면 노출
- 테마(theme.css) 대비·색 토큰 이탈로 안 읽히는 텍스트

## 판정 힌트
- 파일 없음 = 반려 또는 조건부(대체 경로 제안 질문)
- 규칙과 다른 UI 형태 = 조건부 + “의도인지” 질문
- 반복 UI 실수 = 오답노트/rules 재발키
