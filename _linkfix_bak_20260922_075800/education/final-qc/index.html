완성검사

다 만든 옷을 출하 전에 몇 장 뽑아 보는 검사. 전량 안 보고, 정해진 장수만 보고 통과/반려를 정하는 공개 업계 방식. 합격은 항상 바이어 스펙.

출하 전 뽑기 위험·큰문제·작은흠 완성 ≠ 원단 롤

왜 이 칸 왜

최종·출하 전
FINAL

완성 옷을 몇 장 뽑아 본다. 라인 중 잡기와 시점·목적이 다르다.

전수가 기본은 아님
SAMPLE

공개 업계는 정해진 장수만 뽑는다. 전수는 바이어·리스크가 따로 정할 때.

합격 = 바이어
SPEC

이 페이지 숫자로 공장 규격을 정하지 않는다. 작지·바이어 스펙을 본다.

라인 QC: 봉제 중·직후 공정 안 잡기. 완성검사: 로트·출하 단위로 뽑아 판정. 짧게만 — 둘 다 필요, 하나가 다른 하나를 대신하지 않는다.

뽑아 보는 방식 표본

쉬운 말: 전량 안 보고, 정해진 장수만 보고 통과/반려를 정한다. 공개 업계에서 자주 쓰는 방식이다.
표준 이름(참고): AQL · ISO 2859-1. 표 읽는 법만 — 공장 검사 매뉴얼 아님.

검사 수준
LEVEL

일반 I / II / III. 공개 기본은 종종 II. 바이어가 지정.

코드 문자
CODE

로트 크기 + 수준 → 샘플 코드(예: L). 그다음 뽑는 장수·통과/반려 수.

통과·반려 수
Ac / Re

샘플에서 문제 품 수 ≤ 통과면 로트 합격, ≥ 반려면 불합격(해당 계획).

원단검사와 가름 가름

원단 롤 검사
FABRIC

원단검사는 롤 시각 4점(ASTM D5430 계열). 재단 전 원단.

완성 옷 검사
GARMENT

이 칸은 완성 옷·출하 단위로 뽑아 본다. 원단 롤 검사를 대신하지 않는다.

원단이 깨끗해도 봉제·프린트·라벨에서 떨어질 수 있다. 둘 다 별개 칸.

영상 영상

교육용 영상은 이 페이지에 아직 없다.

주의 주의

이 페이지 숫자로 공장 규격을 정하지 않는다. 작지·바이어 스펙을 본다.

퀴즈 확인

1. 뽑아 보는 검사의 뼈대는?

샘플링 검사. 표준 이름: ISO 2859-1 / AQL. 4점은 원단검사 쪽.

2. 공개 연습: 옷 5000장 · 일반 II →?

공개 표: 3201–10000 · II → L → 200.

3. 공개 연습: 큰문제 2.5 · 코드 L의 통과/반려는?

공개 연습 숫자. 공장 규칙 아님.

4. 위험에 공개에서 자주 쓰는 것은?

종종 AQL 0. 항상 바이어 스펙.

5. 큰문제 / 작은흠 공개에서 자주 보는 숫자는?

공개 관행 힌트. 계약이 우선.

6. 원단 롤 검사와 완성 옷 검사는?

../원단검사/

7. 라인 QC와 완성검사의 짧은 가름은?

시점·단위가 다름. 둘 다 필요.

8. 표의 5000→200→통과10은?

바이어 SPEC. 이 페이지 예로 공장 합격을 정하지 않는다.
