# 평균생산수량 논리 재점검 (폐기이력 → 현행)

## 폐기 (2026-09-18)
- avg_day_volume = 일별 전공정 합 → 중복합산, 비현실
- 라인일평균_추정 = 5공정(애리후세·애리달이·와끼오바·어깨스티치·암홀스티치) mean의 **중앙값** → **폐기**
- 이 파일의 옛 「정본·중앙값」 절은 더 이상 정본 아님

## 현행 정본 (2026-09-19) = 애리후세
1. **일평균** = 애리후세 하루 수량 산술평균. 같은 달력일 복수 페이지면 **max** 후 평균
2. **조업일** = 애리후세·날짜숫자 확인된 **달력일** 수 (=일평균 분모)
3. **일지장수** = PDF 페이지 수 (참고, 분모 아님)
4. **주간** = 월~금 / 이번 주는 PDF 있는 날까지
5. **병목** = 참고용(공정 하루평균). 제품 일평균 계산에 안 씀. (미상) 제외
6. **날짜규칙** = 날짜칸에 숫자 없으면 제외(요일만 기입 포함, p-20)
